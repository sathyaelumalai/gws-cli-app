Privacy policy

Last updated: October 16, 2026

gws-cli is a personal tool used only by its developer, with their own Google accounts.

Data accessed

With the account owner's consent, gws-cli accesses Gmail messages, labels and the basic profile (email address) of the signed-in account, in order to read, send and organize that account's own email.

How data is used and stored

  • Data is used only to carry out commands the account owner runs.
  • Sign-in credentials are stored encrypted on the owner's own computer.
  • No email data is collected by, stored on, or sent to any server operated by the developer.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

gws-cli's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from Google Account → Third-party connections.
